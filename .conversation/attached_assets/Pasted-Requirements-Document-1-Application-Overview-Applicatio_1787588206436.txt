1. Application Overview
Application Name: Hammam Ali Omar Taha — Personal Landing Page
Description: A single-page personal landing page served via a business card QR code link. It presents Hammam Ali Omar Taha's professional identity, services, flagship projects, and provides a lead capture form and quick contact links. The page supports Arabic/English bilingual toggle and Light/Dark theme toggle, built as a single self-contained HTML file using Tailwind CSS CDN and Vanilla JavaScript.

4. Business Rules and Logic
4.1 Theme Toggle
Default state: Dark mode (deep black background, Tech Green accents, light text).
Light mode: light/white background, dark text, Tech Green accents retained.
Theme preference is applied instantly on toggle without page reload.
Color palette is strictly limited to: Gray, Deep Black, and Tech Green. No other accent colors.
4.2 Language Toggle
Default state: English (LTR layout).
Arabic mode: all visible text switches to Arabic equivalents; page layout direction switches to RTL.
Toggle applies instantly without page reload.
Both language states must cover all sections including form labels, button text, and navigation.
4.3 Lead Capture Form Routing
Form submission must direct the captured data to hamamhmam72@gmail.com.
Client-side validation runs before submission; invalid or empty required fields block submission and display inline error indicators.
4.4 Single-File Delivery
The entire page must be a single self-contained HTML file.
Tailwind CSS loaded via CDN.
No build step, no external dependencies beyond CDN links.
Must be compatible with standalone static hosting (direct file open or simple static server).
4.5 Mobile-First
Layout and typography are designed for mobile viewports first, then scaled up for tablet and desktop.
Page must load instantly to serve QR code scan traffic effectively.
5. Exceptions and Edge Cases
Scenario	Handling
Form submitted with empty required fields	Block submission; show inline validation error per field
Form submitted with invalid email format	Block submission; show email format error
Language toggle on RTL (Arabic)	All layout containers flip to RTL; form inputs and navigation align accordingly
Theme toggle in mid-scroll	Theme applies globally and immediately without scroll position reset
Quick contact links on desktop	Links open respective apps or web versions (WhatsApp Web, Telegram Web, mail client, LinkedIn)
6. Acceptance Criteria
Open the single HTML file in a browser (or via static hosting URL from a QR code scan).
The page loads in dark mode with English as the default language, displaying the Hero section with name, titles, hook headline, and two CTA buttons.
Click "Explore My Services" — page scrolls to the Services section showing three interactive service cards.
Click "Book a Growth Consultation" (or a service card CTA) — page scrolls to the Lead Capture Form.
Fill in the form fields (name, email, intent, message) and submit — form validates inputs and routes submission to hamamhmam72@gmail.com.
Click the Language Toggle — all page text switches to Arabic and layout direction changes to RTL.
Click the Theme Toggle — page switches to Light mode; color palette updates accordingly.
Tap a Quick Contact Link (e.g., WhatsApp +962781764789) — the respective platform opens.
7. Out of Scope
Backend server, database, or CMS integration.
User accounts, login, or authentication.
Analytics or tracking scripts.
Blog or dynamic content management.
Multi-page routing or SPA framework.
Third-party form submission services (beyond mailto routing).
Animations beyond hover/tap interaction effects on service cards.
