# Hammam Personal Landing Page

A bilingual, mobile-first personal landing page for Hammam Ali Omar Taha — Software Engineer, Web Developer & Designer, Founder of Norv.ai, and Digital Growth & Promotions Expert.

## Highlights

- Arabic / English switch with RTL support
- Dark mode by default with an optional day theme
- Responsive QR-code-friendly layout
- Services and flagship project highlights
- Client-side validated contact form that opens an email draft
- Direct WhatsApp, Telegram, email, and LinkedIn links

## Run locally

```bash
pnpm install
pnpm dev
```

The app is a Vite + React single-page website. Build it for static hosting with:

```bash
pnpm build
```
